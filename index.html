Arbre familial

Les données sont dans un dépôt GitHub privé. Connectez-vous avec votre jeton d’accès personnel.

Comment obtenir un jeton ?

Sur GitHub : photo de profil → Settings → Developer settings → Personal access tokens.

  1. Propriétaire du dépôt (ou membre de l’organisation) : Fine-grained tokens → Generate new token ; Repository access : « Only select repositories » → le dépôt des données ; Permissions → Contents : « Read and write ».
  2. Personne invitée sur le dépôt d’un autre compte : Tokens (classic) → Generate new token ; cochez seulement repo (GitHub ne permet pas encore l’autre type de jeton dans ce cas).
  3. Copiez le jeton et collez-le ici. Il reste enregistré sur cet appareil uniquement.

N’utilisez pas un ordinateur partagé : toute personne ayant accès à ce navigateur pourrait modifier l’arbre.
